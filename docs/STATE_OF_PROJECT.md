# Project state

## Implemented
- Flutter offline app foundation, Persian RTL, Royal Noir style, custom crown illustrations.
- 3 distinct mode entry points and settings: target 8 to 31, optional crown round, per-turn timer, team names.
- Filimo cube toggle only in Filimo. Shah Gol board game cube is not removable.
- Custom game powers and referee actions with deterministic score calculations and undo.
- Custom Shah Gol 'Price of Crown', retreat/duel, point capping.
- Local single-match autosave and match result history with SharedPreferences.
- Custom SVG card illustrations and rules walkthrough.
- Domain and cubit tests added (not yet executed on Android in this environment).

## Not completed or verified
- Official Filimo and Shah Gol board-game mechanics have not been fully verified from official instructions. Those are explicit manual referee modes rather than fabricated automatic rule engines.
- No production asset pipeline for animated 3D dice, bespoke sound design, app icon or polished cinematics.
- No CI or Android release build validation has been executed.
- No official product/license affiliation with Filimo or the Shah Gol board game is claimed.
- No repository branch other than the existing main branch was created.
